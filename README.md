# AI Data Analyst Agent

## Project Overview
AI Data Analyst Agent is a Python-based project that helps users analyze Excel and CSV files.

## Features
- Upload Excel and CSV files
- Data summary and column information
- Missing value detection
- Duplicate value detection
- Sales analysis
- product wise information
- Data visualization and charts
- Business insights and KPI analysis

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- Excel and CSV

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run app.py`
